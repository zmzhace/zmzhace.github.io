# Agent 前沿 2026：RSI、Jev、可验证搜索与 Agent Control

最近关于 Agent 的讨论出现了不少新词：**RSI、System One Model、Agentic Evolution、AI Control**。它们看起来属于不同方向，其实正在拼成同一套系统：

```text
目标与改进方向（RSI / 自动化 AI 研发）
                   ↓
       低成本选择下一步（Jev / 决策模型）
                   ↓
  生成候选 → 执行 → 自动评分 → 保留经验（可验证搜索）
                   ↓
 权限、沙箱、监督、审计、停止机制（Agent Control）
                   └────────── 安全地进入下一轮
```

我把截至 **2026 年 9 月 21 日** 能找到的一手资料和论文整理成了开源仓库：[Agent Frontier Watch](https://github.com/zmzhace/agent-frontier-watch)。这篇文章讲最重要的判断。

---

## 1. RSI：我们到了“AI 帮助改进 AI”，还没到完整自我进化

RSI（Recursive Self-Improvement，递归自我改进）最容易被夸大。让模型修改自己的回答或提示词不等于 RSI；真正的完整 RSI，意味着系统能够自主设计、训练、验证并部署更强的后继系统。

可以把当前进展分成五层：

| 等级 | 系统改进的对象 | 状态 |
|---|---|---|
| L0 | 单次回答，自我反思后重写 | 已普及 |
| L1 | 提示、记忆、工具与 Agent 工作流 | 已投入使用 |
| L2 | 数据、奖励、实验和代码 | 快速发展 |
| L3 | 研究方向与完整训练循环 | 尚未可靠实现 |
| L4 | 自主构建更强的下一代系统 | 未实现 |

2026 年的真实进展主要处于 **L2，并开始接近受监督的 L3**。

OpenAI 在 9 月披露，内部系统已经能在人类监督下完成原本需要熟练研究者数天的明确研究任务，并将它称为“自动化研究实习生”。截至 8 月，其研究组织每个人类工作日大约对应 3.1 个 Agent 工作日。但人类仍负责研究优先级、判断结果以及是否扩大训练。[原始报告](https://openai.com/index/research-acceleration-view-inside-openai/)

Anthropic 则披露，Claude 已经可以在开放研究项目中提出假设、运行实验、让多个 Agent 共享结果并迭代；不过研究问题和评分标准仍由人类确定。Anthropic 也强调，代码量的增长不等于同等幅度的真实生产率提升。[原始报告](https://www.anthropic.com/institute/recursive-self-improvement)

所以我的判断是：

> 执行层的自动化正在快速发生，但研究品味、目标选择、可靠验证和部署权仍然是完整 RSI 的主要缺口。

判断 RSI 进展时，不应该只看“AI 写了多少代码”，而应该看它能否独立提出值得研究的问题、设计能区分假设的实验，并让改进跨任务和跨模型规模迁移。

## 2. Jev：Agent 的“决策层”可能从生成式 LLM 中拆出来

TypeSafe AI 在 9 月 15 日发布了 Jev，称其为首个公开的 **System One Model**。它不生成任意文本，而是接收上下文和候选选项，直接返回结构化选择和概率。

它适合做的不是写文章，而是 Agent 中大量细碎、高频的判断：

- 该调用哪个工具；
- 请求应该交给哪个模型；
- 结果应该通过、重试还是转人工；
- 内容属于哪个类别；
- 当前动作是否越过风险阈值。

传统 Agent 往往让一个生成式大模型包办理解、路由、推理、参数生成和验证。Jev 提出的架构更像这样：

```text
快速决策模型：分类、路由、风险判断
        ↓
生成式大模型：复杂推理、代码和内容生成
        ↓
决策模型 / 验证器：通过、重试、升级人工
```

这条路线有实际吸引力：固定输出结构、高并发和低延迟都适合自动化系统。TypeSafe 宣称 Jev 在自有工作流测试中最高可达到约 193.6 倍速度和 444.6 倍成本优势。[官方发布](https://typesafe.ai/blog/introducing-system-one-models-and-jev)

但现在下结论还太早：这些任务和评估主要来自发布方，Jev 没有公开传统通用基准，且仍处于 early access。一个独立仓库已经开始记录真实 API 的成本、延迟和原始输出，但规模仍然很小。[独立早期测量](https://github.com/WallerChen/jev-measured)

特别要区分两件事：**Schema 永远合法**可以消除格式错误，却不能保证语义判断正确。Jev 最重要的意义暂时不是证明自己已经取代 LLM，而是提出了一个好问题：Agent 的控制面是否应该使用与内容生成完全不同的模型？

## 3. 可验证搜索：Agent 最可靠的自我改进路径

如果一个答案可以自动评分，LLM 就不必一次猜中答案。它可以不断生成候选、执行、评分、诊断失败，再把有效经验带进下一轮：

```text
生成 → 执行 → 评分 → 选择 → 变异 → 再执行
```

Google DeepMind 的 AlphaEvolve 是这条路线最成熟的代表。它让 Gemini 生成和修改程序，再由自动评估函数筛选。2026 年披露的应用包括 TPU 设计、缓存策略、电网优化、量子电路和数学问题；其中某个电网案例中，找到可行解的比例从 14% 提升到了 88% 以上。[AlphaEvolve 进展](https://deepmind.google/blog/alphaevolve-impact/)

2026 年更进一步的变化，是**搜索过程本身也开始成为改进对象**：

- [AEvo](https://arxiv.org/abs/2605.13821) 让元 Agent 编辑控制后续演化的程序或上下文，而不是只生成下一个候选；
- 9 月发布的 [AlgoEvo](https://arxiv.org/abs/2609.15820) 引入分层经验库，从运行反馈中抽取方法、失败模式和可迁移经验。

这类系统最关键的组件其实不是生成器，而是验证器。评分函数如果存在漏洞，Agent 会找到最会“骗分”的方案，而不是真正更好的方案。

因此可验证搜索首先在代码、算法和数学中奏效：它们有编译器、测试、模拟器或明确目标函数。开放式科研和产品决策更难，因为“什么算更好”本身就可能有争议。

可验证搜索是今天最可信的局部自我改进，但仍不等于完整 RSI——问题、评分函数和搜索空间多数仍由人类定义。

## 4. Agent Control：不要只训练一个“好模型”，要设计不会单点失控的系统

当模型只能回答问题时，风险主要在输出；当 Agent 能读取密钥、修改代码、使用浏览器和接触生产系统时，风险来自完整行动链。

Google DeepMind 在 2026 年发布的 [AI Control Roadmap](https://deepmind.google/blog/securing-the-future-of-ai-agents/) 有一个很重要的出发点：即使模型通常是对齐的，也应该把高能力 Agent 当作可能犯错、被攻击或规避限制的内部主体。

一套现实的控制栈至少需要：

1. 对输入做来源、身份和提示注入检查；
2. 根据任务风险分配最小权限；
3. 在沙箱中执行，并限制网络、凭据、时间和资源；
4. 用独立监督器检查计划和关键动作；
5. 对高风险、不可逆操作要求人工批准；
6. 保留不可篡改日志，支持回放和回滚；
7. 用真实事故持续更新评估集和策略。

Chain-of-Thought 目前仍是一个有价值的监控信号。OpenAI 的研究发现，当前推理模型即使知道自己被监控，也不太擅长有意识地控制或隐藏推理过程。[相关研究](https://openai.com/index/reasoning-models-chain-of-thought-controllability/)

但这不能成为唯一防线。未来模型可能学会规避文本监控，或者直接在不可见状态中完成部分推理。2026 国际 AI 安全报告因此把输入输出检测、内部状态监控、沙箱、硬件监测和人类监督放在同一个纵深防御体系中。[完整报告](https://internationalaisafetyreport.org/sites/default/files/2026-02/international-ai-safety-report-2026.pdf)

Agent Control 的核心原则不是“找到一个永远正确的监督模型”，而是：

> 让任何一个模型、工具或审批环节的失败，都不足以直接造成不可逆后果。

## 四条线最终会在哪里汇合？

一个真正能持续改进的 Agent 系统，需要同时拥有：

- RSI 提供研究和改进循环；
- Jev 类决策模型低成本地控制每一步；
- 可验证搜索产生、筛选并积累更好的方案；
- Agent Control 限制权限、发现偏离并安全停止。

现在我们已经看到了每一组零件，也看到了若干局部闭环。尚未出现的，是一个能自主确定目标、改进自身评估方法、训练后继模型，并在没有人类兜底时仍然可靠安全的完整系统。

这也是未来一年最值得观察的分界线：不是 Agent 是否会做更多事情，而是它能否**可靠地决定做什么、证明自己做对了，并在做错之前被叫停**。
